What the app expects back

POST { "image": "<base64>" } and answer with: 

{
  "fishing_net": true,
  "confidence": 0.93,
  "class": "net",
  "objects": [
    { "class": "net", "confidence": 0.93,
      "box": [0.1, 0.2, 0.5, 0.3] }
  ],
  "model": "netsight-net-v1"
}

Only fishing_net and confidence are required. box is [x, y, width, height] in 0–1 image coordinates — that draws the rectangle over the photo.
